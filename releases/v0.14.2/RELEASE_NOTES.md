# v0.14.2-preview.1 — Dracula 코드 가독성 개선

Visual Studio의 **Grokeen Dracula Inspired** 테마에서 변경 비교와 주석, 오류 위치를 더 쉽게 찾도록 개선했습니다.

- 변경 비교의 추가·삭제 단어는 어두운 초록·분홍 배경 위에 밝은 글자로 표시합니다. 스크롤의 변경 위치 표식은 추가 초록·삭제 분홍, 현재 보이는 범위의 테두리는 보라색으로 구분합니다.
- C# 일반 `//`, 블록 `/* */`와 XML 문서 `///` 주석에 서로 가까운 청회색 계열의 구분색을 사용합니다. 문자열 안의 주석 기호는 일반 문자열로 유지합니다.
- 언어 서비스가 보고한 문법·컴파일 오류 위치에는 기존 밑줄에 분홍 테두리를 더합니다. 배경을 채우지 않아 오류가 있는 글자를 가리지 않습니다. 경고와 제안은 오류 강조로 바꾸지 않습니다.
- 선택한 Dracula 편집기 뷰에서 오류·변경 위치 보기를 활성화합니다. 테마를 바꾸면 원래 뷰 옵션을 복원하며 그동안 사용자가 바꾼 값은 보존합니다.

Visual Studio를 닫고 이 버전의 오프라인 설치기를 실행하면 해당 IDE 확장과 테마를 함께 설치합니다. 다시 실행한 뒤 **도구 → 옵션 → 환경 → 일반 → 색 테마 → Grokeen Dracula Inspired**를 선택하세요. 코드 편집기 테마와 AI 대화창의 색상 설정은 별개입니다. 테마의 주석·오류 표시에는 AI 로그인이나 CLI가 필요하지 않습니다. AI 사용에는 네트워크와 해당 서비스 계정이 필요합니다.

VS2017 15.7–15.8용, VS2017 15.9 이상용, VS2019 16.11용, VS2022 17.x용 설치 파일을 제공합니다. 고객 VS2017 Professional 15.7.1과 고객의 별도 오프라인 PC에서의 실측은 포함하지 않습니다.

이 배포는 미리보기 버전입니다. 전체 오프라인 ZIP에는 확장·테마 설치기와 고정된 Codex·Claude CLI가 포함됩니다. 오프라인에서 설치를 준비하고, AI를 사용할 때 인터넷과 서비스 계정을 연결하세요. 사용자 전달 폴더에는 프로젝트 소스·테스트·계정 자료를 포함하지 않습니다.
