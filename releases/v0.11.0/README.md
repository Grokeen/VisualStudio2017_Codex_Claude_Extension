# v0.11.0 — Claude·Codex 협업과 선명한 대화 화면

세 버전의 Debug/Release 6빌드를 오류·경고 없이 완료했고, 실제 VS2017·2019·2022에서 각각145개, 기본 전체16묶음 검사를 통과했습니다. CodexOrig2의 독립 감사에서도 최종 세 DLL의 UI·교차 AI15조건씩과 프로젝트 보호 원문의 경계11조건을 확인했으며 검사 범위의 추가 확정 결함은 없습니다.

같은 팀의 Claude와 Codex를 동료로 지정해 한 요청을 검토하고, 주 담당 AI가 결과를 정리하도록 구성할 수 있습니다. 주 담당 외 최대3명이 각자의 CLI·모델·생각 강도·속도를 사용해 순서대로 한 번 검토합니다. 요청·선택 소스·첨부가 선택한 서비스에 공유되며 각 호출에 사용량이 발생합니다. 동료의 수정안은 자동 적용되지 않습니다.

사용자 메시지를 배경 없는 회색 글자로 표시하고, 답변 배경이 로고를 가리던 문제를 수정했습니다. 전체 액세스의 프로젝트 파일 변경도 실행 종료 후 다시 읽도록 보완했습니다. 미저장 문서·프로젝트 변경은 보존하고, Visual Studio의 전역 파일 알림 설정은 바꾸지 않습니다.

Visual Studio를 닫고 사용 중인 IDE에 맞는 VSIX를 설치한 뒤 **도구 → AI Assistant**를 여세요. 공식 Claude/Codex CLI 설치와 로그인이 필요합니다. 브라우저·Claude 앱 로그인과 CLI 로그인은 별도입니다.

협업은 **대화 목록 → AI 지정하여 대화 → 역할·협업 설정**에서 같은 팀의 열린 동료를 선택하고, 소스를 연 뒤 요청을 전송해 시작합니다. 실패·중지 때는 그 상태를 확인한 뒤 다시 요청하세요. 재귀 자동 대화나 무한 토론은 실행하지 않습니다.

확장을 제거하려면 VS2017에서 **도구 → 확장 및 업데이트 → 설치됨**, VS2019/2022에서 **확장 → 확장 관리 → 설치됨**을 열어 해당 AI Assistant를 제거하고 모든 IDE 창을 닫습니다. CLI·계정·설정·대화 데이터는 이 절차에서 삭제하지 않습니다.
