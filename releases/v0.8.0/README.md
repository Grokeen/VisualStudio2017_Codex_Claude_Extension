# v0.8.0 — 담당 AI를 고르고, 대화와 설정을 더 쉽게 찾으세요

대화 목록 하단에서 새 대화·불러오기·**AI 지정하여 대화**를 사용하세요. 폭이 좁으면 버튼을 가로로 스크롤합니다. AI는 **사용자명+클로드/코덱스+A~Z** 이름을 사용하며, Z까지 지정된 뒤 새 대화 요청은 기존 A의 기록과 초안으로 돌아갑니다.

[VSIX 다운로드](VS2017.AIAssistant-0.8.0.vsix?raw=true) · [상세 사용법](../../docs/USER_GUIDE.md) · [검증 보고](../../MarkdownReport/CodexOrig_TASK-018.md) · [SHA-256](SHA256SUMS.txt)

1. VS2017 15.9 이상을 종료하고 VSIX를 설치합니다. 도구 → AI Assistant에서 사용할 AI와 네이티브 CLI 계정을 연결합니다.
2. 모델·생각 강도·Fast·권한 버튼으로 버튼에 붙은 목록을 엽니다. 모델이 지원하는 강도만 게이지에 표시되며 Fast도 지원 모델에서 선택합니다. 선택 적용으로 저장하고 Esc 또는 목록 밖 클릭으로 닫습니다.
3. 대화 목록 하단 **AI 지정하여 대화**에서 담당자를 선택합니다. 역할·협업 설정에서 역할과 팀을 정하고 같은 팀 동료를 선택하면 실제 순차 검토를 요청합니다.
4. 오른쪽 위 옵션에 마우스를 올려 부채꼴 메뉴를 엽니다. 사용 안내의 카드를 가리켜 강조하고 클릭해 절차 그림과 상세 설명을 봅니다. 목록으로 돌아와 다른 단계를 선택할 수 있습니다.
5. 설정 창 상단 목차로 계정·모델·규칙·화면 구역에 이동합니다. 하단 저장·닫기 버튼은 본문을 스크롤해도 유지됩니다.

기존 Markdown 대화·공통 instruction, 문서 본문 첨부, 대화 폭 조절·숨김·상태·읽지 않음, 변경 파일 이동과 비교·승인·적용·별도 저장을 유지합니다. AI 이름은 자동이며 역할·팀은 편집할 수 있습니다. 계정을 확인하기 전에는 Windows 사용자명으로 표시하고 AI 목록의 계정 이름 다시 확인에서 갱신합니다. 이전 버전의 26개 초과 AI는 기록을 보관합니다.

권한 프리셋은 확장의 DB·형상관리·배포 작업 허용 범위를 선택합니다. 작업 실행 계획·개별 동의와 AI 소스 수정안 승인은 유지됩니다. 협업 호출과 Fast는 사용량이 증가합니다. 문서 본문 지원은 파일 형식과 Windows IFilter 설치 상태에 따릅니다.

현재 VSIX는 VS2017용입니다. VS2019/2022용 확장 패키지, 실제 Claude 인증·Fast 과금 호출, 운영 DB·외부 SVN/TFVC·배포 검증은 후속 범위입니다. 이전 v0.2~v0.7 설치 파일은 보존했습니다. 문서 읽기 도우미 exe/config는 VSIX 안에 함께 포함됩니다.

저장소 전체의 최상위 VisualStudio_AIChat_ExtentionTest.exe에서 기본14개 검사 묶음을 실행할 수 있습니다. 실제 IDE와 실제 AI 계정 검사는 직접 선택합니다.
