# v0.14.0-preview.1 · 협업 메시지와 오프라인 통합 설치

Visual Studio 2017·2019·2022에서 사용하는 AI Assistant의 새 시험 배포입니다. VS2017 15.7 계열용 패키지도 함께 제공합니다.

- **설치가 간단해졌습니다.** `Grokeen-AI-Theme-Offline-Installer-0.14.0.exe`가 설치된 Visual Studio를 찾아 확장과 Kakao·Dracula 테마를 함께 설치합니다. 설치 파일은 EXE에 포함되어 있습니다. 사용 중인 Visual Studio는 직접 닫아 주세요. 중지하면 진행 중 설치가 끝난 뒤 다음 패키지부터 멈춥니다.
- **AI 메시지센터를 추가했습니다.** 같은 팀의 수신자와 본문을 확인해 전송하고, 수신 AI가 읽기 전용으로 답한 실제 회신을 다시 읽을 수 있습니다. 전송 대기와 실제 AI 회신은 별도 상태로 표시합니다.
- **다시 펼친 대화를 가볍게 표시합니다.** 같은 Markdown과 테마를 재사용해 불필요한 문서 생성을 줄였습니다. 협업 파일 잠금 경합으로 화면이 대기하는 경로도 보완했습니다.
- 작업 기록은 클릭으로 열립니다. Dracula 스크롤과 Kakao 영역·탭 대비를 개선했습니다. 실행 중 바뀐 작은 UTF 텍스트 파일은 기존 줄 끝 형식과 인코딩을 보존해 정규화합니다.
- 텍스트 첨부에 아이콘과 전송 분량을 표시합니다. 특수문자가 많은 네 텍스트 파일을 승인 모드로 보낼 때의 요청 크기 오류를 보완했습니다. 모델·생각 강도 선택의 CLI 전달 경계도 검사했습니다.
- 대화 본문에 화면 폭에 맞춘 좌우 여백을 넣고, 작성란과 사용자 말풍선 색을 맞추며 AI 답변을 조금 더 진하게 구분했습니다. 대화 이름·시각은 스크롤해도 상단에 남고, 평소에는 돋보기 입력 버튼, 선택한 대화가 실행·대기 중일 때는 중지 버튼만 표시합니다.
- **중단 위치를 질문 초안으로 가져옵니다.** 디버거가 멈췄을 때 작성란의 `DBG`를 누르면 현재 파일·줄, 열린 소스 앞뒤 최대 세 줄과 호출 함수 최대 세 개를 초안에 추가합니다. 내용을 확인한 뒤 직접 전송하세요. 변수 값·예외 원인을 자동 수집하거나 디버거 실행을 제어하지 않습니다.
- Dracula 우클릭 메뉴·도구 막대 hover와 경계를 구분하고, 중단점 스크롤 표시는 보라색, 오류 표시는 분홍색으로 개선했습니다. IDE의 스크롤 표시 옵션에서 오류와 표시가 활성화되어 있어야 합니다.
- 필수 공통 지침을 최신 1~8번으로 자동 갱신하며 사용자 작성 지침은 보존합니다. TFS/TFVC 최신 받기·체크아웃·체크인에서 PATH 밖의 Visual Studio 도구 탐지를 보완했습니다.

- 설정 저장 중 일시적인 파일 잠금이 발생하면 기존 설정 복구를 제한된 횟수로 다시 시도합니다. 잠금이 계속되면 설정이 일부 저장된 상태일 수 있으며, 외부 작성자의 변경은 덮어쓰지 않고 오류로 안내합니다. 저장 실패 안내가 나오면 설정값과 공통 규칙을 다시 확인하세요.
- 설치 결과에는 실제 존재를 확인한 공식 설치 로그 경로와 사본을 기록합니다. 로그를 확인하지 못한 경우는 설치 종료 코드와 구분해 안내합니다.

CLI까지 오프라인 설치하려면 **FullOffline ZIP**을 받아 전체를 풀고 안내에 따라 CLI 설치도 진행하세요. 작은 ZIP과 단일 EXE에는 CLI 런타임이 들어 있지 않습니다. AI 사용·로그인에는 네트워크와 서비스 계정 권한이 필요합니다.

이 배포는 고객 테스트용입니다. 실제 계정의 AI 응답, 고객 VS2017 Professional 15.7.1 PC, 별도 오프라인 PC와 실제 TFS 서버, 물리 마우스로 조작한 테마 hover·오류 표시는 이번 로컬 검사에 포함되지 않았습니다. 보고된 멈춤 시각의 직접 원인은 확정하지 않았습니다. 프로젝트 소스·PDB·계정 정보는 사용자 설치 묶음에서 제외합니다.
