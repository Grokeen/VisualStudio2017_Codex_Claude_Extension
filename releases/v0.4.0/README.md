# v0.4.0 — 처음 열어도 따라 할 수 있는 Chat

**설정은 한곳에서, 사용법은 네 단계로 확인하세요.** Chat 상단의 **⚙ 설정** 또는 우클릭 **설정**에서 계정·모델·규칙·글자 크기를 화면 중앙 팝업으로 설정합니다. 처음 사용할 때는 요청부터 저장까지 단계별 안내가 나타납니다.

[VSIX 다운로드](https://github.com/Grokeen/VisualStudio2017_Codex_Claude_Extension/raw/refs/heads/main/releases/v0.4.0/VS2017.AIAssistant-0.4.0.vsix) · [상세 사용 안내](../../docs/USER_GUIDE.md) · [프로젝트 소개](../../README.md)

## 설치하고 시작하기

1. Visual Studio 2017 15.9 이상과 사용할 AI의 Windows 네이티브 CLI `.exe`를 준비합니다.
2. Visual Studio를 닫고 `VS2017.AIAssistant-0.4.0.vsix`를 실행해 설치합니다.
3. **도구 → AI Assistant**에서 Chat을 엽니다. 첫 화면의 네 단계 안내를 읽고 **시작하기** 또는 **계정 설정 열기**를 누릅니다.
4. Codex 또는 Claude Code 탭을 선택하고 **⚙ 설정**을 누릅니다. CLI 경로를 지정하고 **계정 연결 → 연결 확인**을 사용합니다. 이미 CLI에 로그인했다면 연결 확인부터 시작합니다.
5. 모델·instruction·글자 크기를 고른 뒤 **✓ 설정 저장**을 누릅니다. 저장하면 팝업이 닫힙니다. **닫기·Esc·창 닫기**는 팝업에서 변경한 입력을 취소합니다.
6. 소스 파일을 선택한 뒤 Chat에서 요청을 입력합니다. 참고 자료는 **＋ 첨부**, **붙여넣기**, 파일 드롭으로 추가합니다.
7. **보내기 → 수정안 검토 → 동의 체크 → 승인 후 적용 → 적용 내용 저장** 순서로 진행합니다. 같은 대화에서 후속 요청을 계속 보낼 수 있습니다.

안내의 **다시 보지 않기**는 다음 실행에도 유지됩니다. 상단 **? 사용 안내** 또는 우클릭 **사용 안내**에서 언제든 다시 열고 선택을 해제할 수 있습니다. 안내 표시 선택은 저장된 CLI 경로·모델·규칙을 보존합니다. 텍스트 영역의 우클릭 복사·붙여넣기와 Ctrl+V도 사용할 수 있습니다.
