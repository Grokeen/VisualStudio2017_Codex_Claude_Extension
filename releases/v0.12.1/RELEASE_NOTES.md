# v0.12.1-preview.1

**오프라인 시험에는 `VisualStudio_AI_Assistant-0.12.1-Preview1-FullOffline-win-x64.zip`을 받으세요.** 확장 네 종류, Codex 0.163.0·Claude 2.1.302 전체 런타임, 독립 IDE 테마 세 종류, 설치 검사 도구와 사용자 PDF가 포함됩니다. 작은 ZIP에는 CLI가 없습니다.

1. ZIP 전체를 압축 해제합니다.
2. 모든 Visual Studio 창을 닫고 `VerifyOfflineSetup.bat`을 실행합니다.
3. 표시된 설치 대상을 선택합니다. VS2017 15.7.1 전용 VSIX가 포함돼 있습니다.
4. 설치 후 **도구 → AI Assistant**를 엽니다. 로그인과 AI 사용 시에는 허용된 네트워크 연결이 필요합니다.

이번 변경은 실행 중 연속 입력과 FIFO 요청, 사용자 메시지 말풍선, 팝업·버튼·하단 여백·탭 간격, 지연된 부채 메뉴, 브랜드 완료 알림과 안전한 결과 유형, 새 문서·코드 파일 저장, 설정의 오프라인 IDE 테마 설치·적용을 포함합니다. 알림에 요청 제목·원문·답변 문장을 전달하지 않습니다.

미승인 수정안에서는 다음 요청이 대기합니다. 승인·적용 또는 명시적 건너뛰기로 진행하며, 원본이 바뀐 기존 대기 요청은 다시 제출해야 할 수 있습니다. 대기는 재시작 후 자동 실행하지 않습니다. 파일 저장은 새 파일 전용이며 기존 파일을 보존합니다.

네 종류의 Release 빌드를 오류·경고 없이 완료했습니다. 기본 회귀 검사 19개, FIFO 58개, 파일 메뉴 68개, 알림 내용 30개와 테마 파일 경계 112개를 통과했습니다. 실제 IDE 테마 검사에서는 선택 ID와 대표 색상 적용 및 시험한 비기본 설정 보존을 확인했습니다. 기본 설정 행이 export에 추가되는 차이는 감사 보고서에 구분해 기록했습니다. 설치·통신 차단 검사와 공개 다운로드 무결성 확인 결과는 공개 배포 기록에서 확인할 수 있습니다.

로그인 없는 Claude 검사와 합성 프로토콜 검사는 실제 계정의 답변 성공을 의미하지 않습니다. 고객의 제한망 PC 및 VS2017 Professional 15.7.1 실측 결과는 별도 확인 대상입니다. 이전 정식 v0.11.1과 공개 시험 배포를 보존하며 이 버전을 최신 정식으로 지정하지 않습니다.

확장 안에서 설치·사용 설명서를 여는 경로도 확인해 수정했습니다.
