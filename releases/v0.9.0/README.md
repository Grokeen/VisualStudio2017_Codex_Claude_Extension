# v0.9.0 — Visual Studio 2017·2019·2022에서 수정과 테스트까지

넓어진 AI 탭, 한 면으로 이어진 입력란, 실제 부채꼴 메뉴와 자세한 도움말을 제공합니다. 추가는 초록색, 삭제는 빨간색으로 표시하며 파일별 비교와 hover 기록을 볼 수 있습니다. 대화 목록 폭 조절·접기·상태·읽지 않음 표시는 유지합니다.

대화만 스크롤하고 입력란은 계속 표시합니다. 작업 상태 카드는 중복 안내를 묶고 마우스 오버로 상세를 펼칩니다. 빈 대화 기록과 우클릭 메뉴에도 검정 테마를 적용했습니다. 설치된 CLI 자동 검색, 숨김 협업·주석 규칙, PDF 설명서와 확인 후 실행하는 CLI 설치 버튼도 포함합니다.

| Visual Studio | 설치 파일 |
|---|---|
| 2017 15.9 이상 | [VS2017 설치](VS2017.AIAssistant-0.9.0.vsix?raw=true) |
| 2019 16.11 | [VS2019 설치](VS2019.AIAssistant-0.9.0.vsix?raw=true) |
| 2022 17.x x64 | [VS2022 설치](VS2022.AIAssistant-0.9.0.vsix?raw=true) |

1. 해당 Visual Studio를 종료하고 맞는 VSIX를 설치합니다. 다시 열어 **도구 → AI Assistant**를 선택합니다.
2. Claude/Codex 탭과 네이티브 CLI `.exe`를 선택합니다. **계정 연결 → 연결 확인**을 진행합니다. 브라우저·Claude 앱의 로그인과 CLI 로그인은 별도입니다.
3. 소스나 선택 영역을 열고 참고 파일을 첨부합니다. 모델 메뉴에서 실제 연결된 모델·강도·Fast를 고릅니다.
4. **승인 요청**은 비교·승인·적용·저장으로 진행합니다. **작업 도구 허용**은 여기에 확장의 DB·형상관리 작업 창을 추가합니다.
5. **전체 액세스**는 네이티브 CLI가 직접 파일 수정·명령·테스트를 실행합니다. 먼저 열린 미저장 파일을 저장합니다. 공개 진행 메시지·실제 사용량 툴팁·변경 카드를 확인합니다.

전체 액세스는 현재 Windows 사용자의 권한으로 실행하며 자동 관리자 승격을 하지 않습니다. 중지 전에 실행한 파일·서버 변경은 남을 수 있습니다. 프로젝트 전후 비교에는 파일 크기·개수·폴더·텍스트 형식의 한도가 있습니다. 실제 변경 전체를 인증하는 감사 로그가 아니므로 [상세 사용법](../../docs/USER_GUIDE.md)을 확인하세요.

모델 목록은 연결할 때 CLI에서 조회합니다. 미제공 토큰은 추정하지 않으며 계정 할당량 퍼센트와 토큰 수를 구분합니다. 사용자 요청은 오른쪽 말풍선, AI 답변과 공개 진행 내용은 왼쪽 본문에 표시합니다. 대화와 공통 규칙은 사용자 PC의 Markdown에 보관합니다.
