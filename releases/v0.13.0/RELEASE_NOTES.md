# Visual Studio AI Assistant 0.13.0 미리보기

응답 준비·실행 중에도 다른 대화방으로 이동하고, 각 방에서 별도 작업을 진행할 수 있습니다. 방마다 요청을 순서대로 실행하며 초안·역할·사용량·취소 상태를 분리합니다. 실행 중인 작업과 대기 요청은 재시작 후 자동 실행하지 않습니다.

이전 기록은 UTC 시간 구간별 Markdown에 나눠 저장하고 위로 스크롤할 때 백그라운드에서 추가로 읽습니다. 화면 전환 뒤 도착한 결과는 현재 대화를 바꾸지 않습니다. 전체 백업에는 대화 Markdown과 같은 ID의 `.history` 폴더가 모두 필요합니다. 구형 기록의 원래 발화 시각은 복원할 수 없습니다.

좁은 창에서 대화방을 더블클릭하면 목록을 접습니다. AI가 질문과 함께 제시한 선택지를 누르면 입력란에 선택 내용이 들어가며 사용자가 확인하고 직접 전송합니다. 숨김 필수 instruction에는 기존 프로젝트 패턴 확인, 최소 수정, 완료 후 감사 요청을 추가했습니다.

수정안의 승인·적용·건너뛰기 절차를 유지합니다. 원래 읽기 전용인 문서는 다른 대화가 실행 중이어도 수정 요청을 거절하고 입력을 보존합니다. 저장된 원문이 바뀐 대기 요청은 자동으로 새 원문을 캡처해 실행하지 않습니다. 내용을 확인한 뒤 다시 제출하세요.

설치 파일은 VS2017 15.7·15.8용, VS2017 15.9 이상용, VS2019용, VS2022 x64용 네 종류입니다. Windows 10 1809 이상 또는 Windows 11 x64와 해당 Visual Studio/.NET 구성요소가 필요합니다. FullOffline 묶음에는 Codex 0.163.0·Claude 2.1.302 런타임과 라이선스·고지가 들어 있습니다. 설치와 CLI 시작은 오프라인으로 처리할 수 있으며 계정 인증과 AI 사용 시에는 서비스 연결이 필요합니다.

네 종류의 Release 빌드는 오류·경고 0이며 기본 회귀 검사 20개 묶음, 동시 대화 120개, 저장 경계 19+13개와 비동기 기록 UI 소스 검사 10개를 통과했습니다. 같은 담당 AI를 다시 선택할 때 미승인 수정안이 사라져 대기가 멈추던 문제도 수정했습니다. 설치된 IDE 검사와 배포 파일의 해시 등 상세 증거는 [이 버전의 릴리스](https://github.com/Grokeen/VisualStudio2017_Codex_Claude_Extension/releases/tag/v0.13.0-preview.1) 및 저장소의 TASK-068 검증 보고서를 확인하세요.

프로젝트 최상위 `UserDistribution/v0.13.0`은 설치 파일·필수 CLI 런타임·설치/검증 도구·문서·체크섬만 전달하는 폴더입니다. 프로젝트 소스·PDB·테스트·개발 기록·계정 자료는 포함하지 않습니다. 기존 GitHub 소스 공개 방식은 유지합니다. 새 배포의 다운로드 검증 후 첨부 파일과 로컬 releases에는 새 버전과 직전 0.12.1을 보존하고 이전 첨부를 정리합니다. 릴리스 이력·태그·개발 및 감사 기록은 보존합니다.

Claude 로그인과 실제 AI 답변은 사용자 요청에 따라 검사하지 않았습니다. 고객 VS2017 Professional 15.7.1 및 별도 제한망 PC의 실제 설치는 사용자 환경에서 추가 확인해야 합니다. 설명서의 합성 UI 이미지는 실제 IDE 화면이나 물리적인 마우스·키보드 조작 기록이 아닙니다.
