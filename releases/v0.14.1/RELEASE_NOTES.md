# v0.14.1-preview.1 — 대화 색상 구분 개선

요청 입력란과 사용자가 보낸 메시지는 같은 배경색으로 표시하고, AI 답변은 같은 색 계열의 더 어두운 배경으로 표시합니다. Dracula에서는 사용자 `#4B4F63`, AI `#303342`을 사용합니다. Visual Studio 다크·라이트와 Kakao 다크·라이트도 같은 원칙으로 조정했습니다.

Visual Studio 2017 15.7–15.8, 2017 15.9 이상, 2019 16.11, 2022 17.x의 설치 파일을 각각 제공합니다. 설치 파일과 테마는 한 EXE로도 오프라인 설치할 수 있습니다. 이전 v0.14.0-preview.1 배포 파일은 별도 릴리스로 유지합니다.

검증: 네 가지 VSIX Release 빌드, 소스 검사 26/26, 다섯 테마의 WPF 렌더 캡처와 사용자·AI 표면색 및 글자 대비 검사 통과. 고객의 실제 Visual Studio 2017 15.7.1 PC와 실제 AI 계정 요청은 이번 로컬 검증에 포함되지 않았습니다.
