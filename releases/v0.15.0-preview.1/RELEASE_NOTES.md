# v0.15.0-preview.1 미리보기 릴리스 노트

Visual Studio AI Assistant v0.15.0-preview.1의 사용자 기능 안내입니다.

- Claude·Codex 대화를 활동함에서 확인합니다. 본문 표시 조건에 따른 자동 읽음과 사용자가 선택하는 `✓ 읽음 처리`를 구분합니다.
- 제공자 모델 목록 조회가 실패해도 저장된 모델 설정을 유지합니다. 현재 선택한 제공자의 runtime metadata에 유효한 quota 사용량이 있을 때만 남은 비율을 표시하고, 값이 없거나 유효하지 않으면 확인 불가로 안내합니다. 토큰 수나 남은 문맥량을 추정하지 않습니다.
- 솔루션별 대화 기록과 문맥을 구분합니다. 실행·대기·협업 작업이 끝날 때까지 전환을 미루며, 대기 중 새 요청과 문맥 캡처를 막고 초안과 기록을 보존합니다.
- 사용자가 C# 주석을 선택하고 요청을 확인한 뒤 설정된 CLI로 보내며, 제안 코드를 검토하고 명시적으로 수락하면 편집기 커서에 삽입합니다. 입력 중 자동 요청이나 ghost text는 제공하지 않습니다.
- 내부 Markdown 작성기에 H1/H2/H3 제목 버튼이 있습니다. 선택 영역 또는 현재 줄의 제목 수준을 지정합니다. 일반 Visual Studio `.md` 편집기의 실시간 미리보기 기능은 포함하지 않습니다.
- 저장하지 않은 Markdown을 닫을 때는 고정 확인 영역에서 `저장 후 닫기`, `변경 버리고 닫기`, `계속 작성` 중 선택하도록 안내합니다. 저장 대화상자를 취소하거나 저장에 실패하면 작성기를 열린 상태로 유지합니다.

## Preview 확인 범위

활동함 이미지는 합성 UI이며, C# 주석 코드 요청은 실제 Visual Studio 화면 캡처가 아닌 설명용 흐름도입니다. 실제 Visual Studio GUI, 계정 인증과 실제 AI 응답, 계정별 quota, SDK 설치 호환, IME, native Undo는 검증되지 않았습니다. 비GUI 검사는 이러한 환경의 동작을 증명하지 않습니다. [오프라인 설치 안내](../../docs/OFFLINE_INSTALL.md)와 [사용자 안내서](../../docs/USER_GUIDE.md)를 참고하세요.
