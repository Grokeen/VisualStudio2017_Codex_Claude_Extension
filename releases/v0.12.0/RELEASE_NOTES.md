# v0.12.0-preview.1

2026-10-20 · 설치 패키지 버전 0.12.0

- Windows 작업 완료 알림과 사용 여부 설정을 추가했습니다.
- 공통 팝업의 제목 표시줄·창 제어·본문·하단 동작을 같은 테마로 정리했습니다.
- 설정을 왼쪽 네 페이지로 나누고, 안내의 뒤로 버튼을 왼쪽 위에 배치했습니다.
- Claude/Codex 탭의 키보드 이동·간격과 Markdown 창 크기·체크박스·여섯 도구 그룹을 개선했습니다.
- 안전한 웹/소스 링크를 굵게 표시하고 URL 번호의 콜론·설명 열을 맞췄습니다. 긴 파일 링크는 제목과 설명을 나눕니다.
- 최근 대화 20개를 먼저 표시하고 위로 이동하면 이전 20개를 추가합니다. 저장 모델·AI 문맥과 화면 표시 범위를 분리했습니다.
- 확장 내부 Kakao/Dracula 팔레트와 AI 확장 없이 설치 가능한 세 IDE용 테마 패키지를 제공합니다.
- 주요 화면 모션을 220ms EaseOut으로 통일하고 Windows 모션 감소 설정을 따릅니다.
- PDF 23쪽과 새 화면/GIF 안내를 제공합니다. 이전 18쪽 원본과 과거 배포 파일은 보존했습니다.

감사 R53-01의 HTML 속성·주석 URL 승격과 R53-02의 OS 제목 표시줄 잔여를 수정하고 고정 후보로 재감사했습니다. 초기 실패와 이후 통과 근거는 각 작업 보고서에 따로 보존했습니다.

이는 공개 시험 배포입니다. 기본 16개 검사와 개발 PC의 실제 IDE 통과를 고객의 VS2017 15.7.1 또는 제한망 PC 설치 성공으로 확대하지 않습니다. NotifyIcon 알림은 WinRT toast 활성화/클릭 복귀와 다르며, 대화 저장은 기존 100개·4MB 한도를 유지합니다. 독립 테마는 설치·구성 등록을 확인했으며 모든 IDE 화면의 전환/대비를 실측한 것은 아닙니다.
