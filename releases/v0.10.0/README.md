# v0.10.0 — 읽기 쉬운 답변과 Markdown 작성기

Visual Studio 2017·2019·2022에서 서식 있는 답변과 소스 링크를 확인하고, 입력란을 우클릭해 Markdown을 작성·미리보기 할 수 있습니다. 문서 폴더의 파일 목록, 현재 저장·다른 이름 저장, 이름 변경·확인 후 삭제를 제공합니다. 작은 창에서는 문서 목록과 작업 버튼을 스크롤로 확인할 수 있습니다.

Visual Studio 테마를 우선 따르는 자동 모드와 수동 Light·Dark, 스크롤 가능한 변경 팝업, 접이식 설정 설명과 안내 GIF를 추가했습니다. 목록 폭 조절·숨김·대화별 상태·읽지 않음 표시는 유지합니다.

| Visual Studio | 설치 파일 |
|---|---|
| 2017 15.9 이상 · x86 IDE | [VS2017 설치](VS2017.AIAssistant-0.10.0.vsix?raw=true) |
| 2019 16.11 · x86 IDE | [VS2019 설치](VS2019.AIAssistant-0.10.0.vsix?raw=true) |
| 2022 17.x · x64 IDE | [VS2022 설치](VS2022.AIAssistant-0.10.0.vsix?raw=true) |

1. Visual Studio를 닫고 해당 버전의 VSIX를 설치합니다. 다시 열어 **도구 → AI Assistant**를 선택합니다.
2. **설정 → 계정 로그인 화면**에서 공식 CLI 로그인과 연결 확인을 진행합니다. 브라우저·Claude 앱의 로그인은 CLI 로그인과 별도입니다.
3. 소스·이미지·문서를 첨부하고 요청을 입력합니다. **Enter**는 전송, **Ctrl+Enter**는 줄바꿈입니다.
4. 변경을 먼저 비교·승인하거나 **전체 액세스**로 파일 수정·명령·테스트를 맡깁니다. 전체 액세스는 현재 Windows 사용자의 권한으로 동작합니다.
5. 긴 내용을 작성하려면 **입력란 우클릭 → Markdown 편집**을 엽니다. 작성기에서 **적용**하면 원래 입력란으로 돌아옵니다. 독립 문서의 저장과 입력란 적용을 구분하세요.

![연결·요청 안내](../../docs/assets/guide-media/01-connect.gif)

안내 GIF는 별도 WPF 예제로 만든 절차 설명입니다. 실제 계정 인증·설치·유료 AI 요청 성공을 의미하지 않습니다. 같은 안내는 확장의 설정·사용 안내에서도 볼 수 있습니다.

Markdown 미리보기는 표·코드 강조·참조 링크와 제한된 정적 HTML을 표시합니다. CSS·JavaScript·iframe 실행이나 원격 이미지 자동 로딩은 제공하지 않습니다. 로컬 이미지와 상대 소스 링크는 명시적으로 연 문서를 기준으로 처리합니다.

세 버전의 Debug/Release 빌드가 오류·경고 없이 완료됐습니다. 실제 VS2017·2019·2022에서 각각133개, 기본 전체16묶음, 실제 마우스28개·GIF 재생과 종료24개 검사를 통과했습니다. 독립 감사에서 지적한 링크·작성기·HTML·표 한도·삭제 확인·좁은 화면 문제도 수정 확인했습니다. 상세 범위와 이전 실패는 위 검증 기록에 공개합니다.

기존 CLI 설치 설명서·배치·고객 전달 ZIP과 v0.2~v0.9 설치 파일은 보존했습니다. 실제 Claude CLI 계정·운영 SQL Server·외부 TFVC·운영 배포의 미검증 범위는 격리 검사 결과와 구분합니다.
