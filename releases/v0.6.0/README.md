# v0.6.0 — 대화 목록 크기 조절과 대화별 상태

대화 목록의 오른쪽 경계를 드래그해 폭을 조절하고 왼쪽 끝으로 끌어 숨길 수 있습니다. ☰로 다시 열면 마지막 폭이 복원되며 다음 실행에도 유지됩니다. 작업 중·완료·실패·중지, 읽지 않은 응답의 파란 점을 대화마다 구분합니다. 상태와 읽지 않음은 Markdown에 저장하고 대화 선택·본문 확인으로 읽음 처리합니다.

[VSIX 다운로드](VS2017.AIAssistant-0.6.0.vsix?raw=true) · [상세 사용법](../../docs/USER_GUIDE.md) · [화면 예제](../../docs/assets/chat-0.6-preview.png) · [검증 보고](../../MarkdownReport/CodexOrig_TASK-014.md)

1. VS2017 15.9 이상을 종료한 뒤 VSIX를 실행해 설치합니다.
2. 도구 → AI Assistant를 열고 사용할 AI와 네이티브 CLI 계정을 설정합니다.
3. 대화 목록 경계에서 마우스를 끌거나 키보드 좌우 방향키로 폭을 조절합니다. ☰는 숨김과 복원입니다.
4. 대화 옆 상태·툴팁을 확인합니다. 완료 표시와 코드 승인·적용·저장은 별개입니다.

저장소 전체를 받은 경우 루트 VisualStudio_AIChat_ExtentionTest.exe로 기본 검사8개 묶음을 실행할 수 있습니다. 실제 IDE와 계정 AI 검사는 직접 선택합니다. 검사 준비 조건과 로그 위치는 [개발 문서](../../docs/DEVELOPMENT.md)를 참고하세요.

현재 패키지는 VS2017용이며 VS2019/2022 확장 지원은 포함하지 않습니다. 실제 Claude 계정·외부 운영 DB/SVN/TFVC·배포 서버는 검증하지 않았습니다. 기존 v0.5.0 릴리스는 보존합니다. 패키지 해시는 [SHA256SUMS.txt](SHA256SUMS.txt)에 있습니다.
