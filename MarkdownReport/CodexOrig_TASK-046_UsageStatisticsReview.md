## 적용 가능 범위

[GraphPane.cs](C:/dydgyqud/Markdown_Memo_Interchange/RemoteControlDemo/Features/Graph/GraphPane.cs)는 WPF의 표 편집과 Canvas 그래프 렌더링을 결합한 화면이다. 막대·선 표현, 크기 변화에 따른 다시 그리기, 값 설명 방식은 읽기 전용 사용량 통계 화면의 참고 자료로 사용할 수 있다. 표 편집·소스 보기·차트 작성기 전체를 가져오거나 다른 앱의 실행 참조를 추가하는 작업은 하지 않는다. 다른 프로젝트 파일은 읽기만 했다.

현재 [ProviderRuntime.cs](../src/VS2017.AIAssistant/Providers/ProviderRuntime.cs)의 `ProviderUsageSnapshot`은 nullable 토큰·계정 한도·출처를 보관하고, [AssistantControl.Runtime.cs](../src/VS2017.AIAssistant/Views/AssistantControl.Runtime.cs)는 현재 요청에 해당하는 이벤트를 화면에 반영한다. 이 상태를 요청별 로컬 통계 이력으로 누적하는 경로는 현재 Chat 저장소에서 확인되지 않았다. 그래프 이전에 별도 집계·저장 경계가 필요하다.

## 차기 후보에 유지할 조건

- 설정의 계정 영역에서 사용량 통계로 진입하며 사용자가 명시적으로 기록을 켠 뒤의 요청만 저장한다. 완료·실패·취소와 경과 시간을 구분하고 기록 삭제를 제공한다.
- 요청 종료 요약을 최대 한 번 기록한다. 스트리밍 이벤트·중복 종료·늦은 이벤트·재시도로 같은 요청을 중복 집계하지 않도록 검증한다.
- 계정 전체 할당량과 이 확장에 기록된 요청 합계를 분리한다. 미제공 수치는 미확인으로 유지하고 보고되지 않은 비용을 추정하지 않는다.
- 날짜·제공자·모델·실제 보고 수치·상태·경과 시간만 허용한다. 프롬프트·첨부·소스·파일 경로·계정명·인증 토큰·연결 문자열을 저장하지 않는다.
- 첫 화면은 일별 막대/선과 읽기 전용 표·요약을 기준으로 한다. 좁은 창, 긴 이름, 애니메이션 설정, 키보드와 보조 기술 접근을 고려한다.

추가로 집계 단위를 먼저 확인해야 한다. 현재 [ParseUsage](../src/VS2017.AIAssistant/Providers/ProviderRuntimeService.cs)는 Codex `thread/tokenUsage/updated`의 `tokenUsage.total`을 읽으며 다른 경로는 `turn.completed`의 `usage`를 읽는다. 코드에 서로 다른 출처가 있으므로 **마지막 스냅샷을 한 번 저장하는 것만으로 요청별 합계의 정확성이 보장되지는 않는다.** 프로토콜별 요청/turn/누적 범위를 공식 계약·합성 이벤트로 확인하고, 누적이면 검증된 기준값·초기화 처리 없이 일별 요청 합계에 더하지 않는다. 이 검토에서는 그 프로토콜 단위를 실제 계정으로 검증하지 않았다.

현재 모델은 입력을 ‘캐시 포함’으로 표시한다. 캐시 토큰을 입력에 다시 더하지 않도록 하고, null과 실제 0을 구분하며 보고된 요청 수의 범위도 표시해야 한다. 중복 이벤트, 누적값 초기화, 미제공 값, 제공자 전환, 날짜 경계/시간대, 취소·실패, 옵트인 전 구간, 손상·삭제된 기록을 합성 자료로 검증하는 조건을 추가한다.
