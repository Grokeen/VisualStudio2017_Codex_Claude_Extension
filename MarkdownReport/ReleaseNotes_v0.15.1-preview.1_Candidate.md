# Visual Studio AI Assistant v0.15.1-preview.1 · 출하 노트 후보

> 상태: 문서 검토 후보입니다. 2026-11-08 기준 v0.15.1 설치기 EXE와 최종 ZIP은 없으며, 실제 Visual Studio 설치·GUI 동작도 확인되지 않았습니다. 출하 시에는 통합된 패키지의 버전·파일 구성과 검증 결과를 대조한 뒤 이 내용을 확정해야 합니다.

## 사용자에게 안내할 변경

- C# 주석 코드 제안 메뉴를 선택하면 전송 전에 임시 중지 안내를 표시하는 소스 후보입니다. 현재 공개 v0.15.0은 이 요청을 자동으로 차단하지 않으므로, 공개 설치본에서는 해당 메뉴를 사용하지 말고 전송 확인 창이 나오면 거절하세요.
- 임시 중지는 C# 주석 코드 제안 요청에 한정됩니다. 일반 대화 기능이 같은 방식으로 중지된다는 뜻은 아닙니다. 소스 후보의 기대 동작은 요청 원문을 AI로 전송하거나 편집기 문서를 변경하지 않는 것이지만, 실제 Visual Studio 동작은 아직 검증되지 않았습니다.
- 오프라인 설치 안내에서 공개 v0.15.0의 구형 `VerifyOfflineSetup.bat`과 ZIP checksum 확인을 구분했습니다. FullOffline과 간단 ZIP의 외부 archive hash 자료도 별도로 설명합니다.
- 미공개 오프라인 검증 후보는 FullOffline 패키지의 필수 확장·테마 파일과 체크섬·경로를 검사하도록 설계됐습니다. 완성 0.15.1 ZIP, 설치기 EXE, 공식 CLI·공식 서명 및 실제 설치 결과는 아직 확인되지 않았습니다.

## 검증 범위

이 출하 노트는 소스·문서 후보에 대한 설명입니다. 최종 ZIP 검증, 실제 Visual Studio IDE, 고객 PC 설치, 인증 또는 AI 요청 성공을 보증하지 않습니다. 배포 전에 동일한 버전의 설치기·확장·테마·CLI manifest·사용자 설명서가 함께 들어 있는지 최종 패키지에서 확인해야 합니다.
